# ssh-hardening

> Políticas restritivas de acesso remoto seguro e proteção contra ataques de dicionário.

## 🛠️ Tecnologias & Componentes
- `sshd_config, chaves Ed25519, banners, fail2ban`

## 📋 Boas Práticas e Padrões de Produção
- Mantenha configurações desacopladas e declarativas.
- Nunca versione senhas, chaves privadas ou tokens em texto puro.
- Siga as diretrizes de padronização corporativa do módulo [`02-seguranca`](../).
