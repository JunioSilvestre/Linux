# 09 — Configurador e Notificador de Diagnóstico Preditivo SMART com smartd

## 🛠️ Ferramentas e Utilitários Nativos Utilizados
`smartd.conf, smartctl, logger`

## 📌 Exemplo de Execução CLI
```bash
./configure_smartd.sh --email noc@corp.com
```
