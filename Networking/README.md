# Enterprise Linux Networking

This directory provides architecture guides, CLI workflows, and configuration standards for enterprise Linux networking.

## Domain Structure

| Directory | Focus Area |
|---|---|
| [Firewalls](Firewalls/README.md) | `nftables`, `iptables`, `firewalld`, `ufw` |
| [Routing](Routing/README.md) | Policy routing, multi-homed routing, metric control |
| [Diagnostics](Diagnostics/README.md) | `ss`, `ip`, `tcpdump`, `wireshark`, `ethtool`, `traceroute` |
| [VLANs](VLANs/README.md) | 802.1Q tagged interfaces, bond/team aggregation |
| [VPN](VPN/README.md) | WireGuard enterprise site-to-site and client configurations |
