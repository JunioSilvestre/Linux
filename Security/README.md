# Enterprise Linux Security & Hardening

Security engineering standards, CIS benchmark auditing, mandatory access control, and host defense mechanisms.

## Subdirectories

- [Hardening](Hardening/README.md): OS baseline configuration, CIS Level 2 profiles, kernel sysctl flags.
- [SELinux](SELinux/README.md): Mandatory Access Control policy writing, context remediation, boolean flags.
- [Auditing](Auditing/README.md): Linux Audit Framework (`auditd`), rule generation, alerting.
