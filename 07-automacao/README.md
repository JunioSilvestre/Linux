# 07-automacao — Automação Operacional de Infraestrutura

Padronização de tarefas administrativas recorrentes com Ansible, Python e Shell Scripting.

## 📂 Subáreas
- [`ansible/`](./ansible) — **Stack:** `ansible-playbook, roles, inventory` — Configuração declarativa e orquestração de frotas de servidores Linux.
- [`python/`](./python) — **Stack:** `psutil, os, subprocess, paramiko` — Scripts para extração de relatórios, interação com APIs e verificações de integridade.
- [`bash/`](./bash) — **Stack:** `scripts utilitários, automação de backups` — Scripts rápidos para rotinas locais e integração com crontab/systemd timers.

## 📌 Guia de Execução & Padrões
- Todas as implementações desta pasta seguem os padrões de produção estabelecidos para Linux.
- Consulte os READMEs de cada subárea para detalhes sobre ferramentas e boas práticas.
