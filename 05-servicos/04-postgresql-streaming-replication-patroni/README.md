# 04 — Cluster de Banco de Dados PostgreSQL com Streaming Replication e Patroni HA

## 🏢 Cenário de Produção e Vida Real
Alta disponibilidade e failover autônomo de banco de dados sem perda de dados (RPO=0).

## 🚀 Arquitetura e Engenharia Linux
Implementação de engenharia avançada de sistemas Linux para produção, assegurando confiabilidade, resiliência, observabilidade e adesão estrita aos padrões de conformidade corporativa.

## 🛠️ Ferramentas e Utilitários Nativos Utilizados
`patronictl, psql, pg_basebackup`

## 📌 Exemplo de Execução CLI
```bash
patronictl -c /etc/patroni.yml topology
```
